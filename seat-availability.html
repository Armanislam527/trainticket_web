Bangladesh Railway seat availability

Choose a route and date to check current availability from the railway API. Local JSON files are used only to autocomplete train and station names; live seat counts are fetched when you submit.

How availability is queried

The existing scanner requests one route at a time using GET /web/bookings/search-trips-v2 with from_city, to_city, date_of_journey, and seat_class. Results include trains and per-class seat_counts.online, seat_counts.offline, and fares.

This page submits one request per click; it does not scan every route pair. The API requires an authorized user session. If it returns 401, enter your own current access token below. Credentials stay in this page's memory and are sent only to your configured proxy.
