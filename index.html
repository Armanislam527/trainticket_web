Train schedule search

Search the server-provided train list by name, number, or route. Selecting a train requests its full route and schedule details.

Frontend-only API access

This follows the official frontend flow: load GET /all-trains/info, filter the returned trains in the browser, then request the selected schedule with POST /train-routes. The official train list contains train numbers and routes, but not train names; known display names are mapped locally.

The API currently permits browser access from https://eticket.railway.gov.bd. CORS is enforced by the browser, so other localhost or production origins work only if the API owner allows them. Frontend code cannot bypass that policy.
